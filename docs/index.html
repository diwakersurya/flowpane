What it shows

  

    
Flow
Turns, newest first. Tool calls appear live with their status. A subagent folds into one line until you open it.

    
Todos
The agent's task list from TodoWrite or TaskCreate/TaskUpdate, with progress and the current step.

    
Decisions
What was chosen, why, and what was rejected, linked back to the turn that made the choice.

    
Context
Tokens used and tokens left, so you know when to start a fresh chat.

  


  
Install

  
Needs Claude Code 2.1.289 or newer. Flowpane uses the early-access function-hook plugin API.

  
claude plugin marketplace add diwakersurya/flowpane
claude plugin install flowpane@flowpane

  
Then run /flow. The pane also opens by itself in terminals at least 144 columns wide.


  
Commands

  

    

      
CommandDoes

      
/flowOpens or closes the pane

      
/flow todos · decisions · flowOpens the pane on that tab

      
/flow clearClears the panel. The conversation is untouched

    

  


  
Why a native pane

  
A browser page with three.js or React Three Fiber would mean a second window, a local server and a port. A separate TUI would mean tailing an undocumented transcript file. Flowpane runs inside Claude Code as a mod: it gets every event first-hand and draws in the terminal, the desktop app and VS Code. Flow, todos and decisions are a graph, a list and a log, and a third dimension wouldn't add anything.


  
Privacy

  
Everything stays local. No network calls, no keys, no file contents stored. The opt-in decision extraction uses your own Claude Code session's model.
