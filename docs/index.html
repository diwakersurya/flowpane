Flowpane

Why a mod

  

    
Pinned rules
Injected into the system prompt, so the agent still follows them after /compact and 200 messages later. Saved per project.

    
Live guards
Read-only, No git push, Ask before Bash: one press to switch on or off for this session, enforced at the permission check.

    
Ask aside
A forked, tool-free question over the conversation, using its prompt cache. The agent never sees it and its context doesn't grow.

    
Selection
Select text in the transcript, then Explain it aside, Quote it into your prompt, or Pin it as a rule.

  


  
Install

  
Needs Claude Code 2.1.289 or newer. Flowpane uses the early-access function-hook plugin API.

  
claude plugin marketplace add diwakersurya/flowpane
claude plugin install flowpane@flowpane


  
Commands

  

    

      
CommandDoes

      
/flowOpens or closes the panel. /flow pins and /flow ask open a tab

      
/pin <rule>Pins a rule. /pin alone lists your pins

      
/ask <question>Asks aside; the answer shows in the panel

    

  


  
Privacy

  
Everything stays local. Pins live in the plugin's store on your machine. Ask-aside requests go through your own Claude Code session. Guards are a convenience, not a sandbox.
